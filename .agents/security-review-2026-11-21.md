# Security review of the code since v0.9.1 (2026-11-21)

The November scan (`november-26-findings.md`) read the code as of v0.9.1. About 60,000 lines of non-test code landed after it, unreviewed, so the owner asked for a security review of it (branch dry-clean, PR #129). Ten readers took one area each and reported only security, data-loss and crash defects, each with a scenario; nothing was built or run by them. Each finding is checked against the code before it's fixed.

**61 findings:** 8 high, 21 medium, 32 low; some are the same defect found by more than one reader (packages#1 = enterprise#2 = service#1; packages#2 = enterprise#1; service#2 = files#4; databases#4 ≈ tools#4).
