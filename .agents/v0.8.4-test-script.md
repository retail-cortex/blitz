# v0.8.4 manual test script

Branch `release-0.8.4`. Work through it top to bottom: later parts reuse
what earlier ones set up. Each step says what to do and what you should
see. Note anything that doesn't match (the step's number is enough) and
I'll fix the whole list in one round before the full suite runs.

Plan about 90 minutes. The parts marked 💲 call a model (a few cents).

## 0. Set up

1. Build the app and the CLI:
   ```sh
   bazel build //:mac-app //apps/cli:blitz
   ```
2. Quit Blitz, replace `/Applications/Blitz.app` with
   `bazel-bin/apps/electron/packaging/darwin_arm64/Blitz.app`, and open it.
   When it offers to restart the service, accept. Settings › About shows
   the local build.
3. Make a scratch workspace with a few files:
   ```sh
   mkdir -p ~/blitz-084/docs && cd ~/blitz-084 && git init -q
   printf '# Notes\n\nSome text.\n' > docs/notes.md
   ```
   Open `~/blitz-084` in the app. Turn on **Show advanced** in Settings.
4. On your desktop, put a picture (`shot.png`), a PDF, a folder with two
   files in it, and a file over 32 MB (a video, or
   `mkfile 40m ~/Desktop/big.bin`).

## 1. Drag and drop with your computer (#70)

1. Drag `shot.png` from Finder onto `docs` in the tree.
   **Expected:** a dialog, **Copy here** / **Move here**. Choose **Copy**:
   `docs/shot.png` appears and is selected; the original is still on the
   desktop.
2. Drag it onto `docs` again. **Expected:** after Copy/Move, a second
   question: **Replace**, **Keep both**, **Skip**. **Keep both** gives
   `docs/shot 2.png`.
3. Drag the folder onto the tree's background and choose **Move**.
   **Expected:** the folder and both files at the top level; the
   original folder is in the Trash.
4. Drag `big.bin` onto `docs`, **Copy**. **Expected:** it arrives whole
   (`ls -l ~/blitz-084/docs/big.bin` is 40 MB).
5. Drag `docs/notes.md` from the tree onto the desktop. **Expected:** a
   copy on the desktop; the workspace keeps its file.
6. **Risk to check:** drag a row onto another folder *inside* the tree.
   **Expected:** it moves, as before. (Every row drag is now the system's
   own drag; if this breaks, it's the one place that can.)

## 2. Pictures in Markdown (#71)

1. Open `docs/notes.md`, switch to **Visual**, put the cursor at the end
   and choose **Image…** in the toolbar. **Expected:** a grid of the
   workspace's pictures with thumbnails; typing `shot` narrows it;
   choosing one fills in `shot.png` and a description.
   **Insert**: the picture's box appears.
2. Drag `docs/shot 2.png` from the tree into the text. **Expected:**
   `![shot 2](shot%202.png)` at the drop point, a space from the words.
3. Drag `shot.png` from Finder into the document. **Expected:** saved in
   `docs/` (as `shot 3.png`) and linked.
4. Take a screenshot to the clipboard (⌃⇧⌘4) and paste in the document.
   **Expected:** `docs/pasted-2026-…png`, linked.
5. Switch to **Source** and repeat steps 2 and 3. **Expected:** the same
   Markdown.
6. Drop the PDF. **Expected:** a link (`[file.pdf](file.pdf)`), not an
   image.

## 4. Jobs (items 9–12)

1. 💲 In the chat: "Create a job that runs every day at 8 am to fetch the
   latest news from news.google.com on AI and write a summary report
   into reports/ai-news in month-day-year.html, glass morphic with a
   dark theme."
   **Expected:** an approval showing the WORKER.md diff and the next
   runs, whatever the permission mode. Approve: a card with the
   schedule, `web:news.google.com` and `write:reports/ai-news/**`,
   **Review** and **Enable**.
2. **Review**: Studio › Jobs opens on it. Back in the chat, **Enable**:
   the card says when it next runs.
3. 💲 Studio › Jobs › **New job** › **Compose with AI**: describe the news
   job. **Expected:** a question or two (the time zone), then a draft with
   its schedule, permissions and prompt; **Use this job** fills the form.
   Cancel it, then **New job** again:
   - **Repeats** › Every week, Monday and Friday, 08:00. **Expected:**
     "Every Monday and Friday at 8:00 AM" with `0 8 * * 1,5` as a chip,
     the next five runs as dated rows ("in 3 days"), and their days filled
     on the month (today ringed; the arrows step months).
   - **Time zone** is a dropdown by region with offsets; choose Europe ›
     Paris: the runs move to Paris time.
   - **Custom**, type `whenever`. **Expected:** "Blitz can't read this
     schedule".
   - **May do without asking** › **Add a rule** twice: **Fetch from the
     web** `news.google.com`, **Write files** `reports/**`. **Expected:**
     each row says what it allows. The **?** on the Write files row lists
     what patterns cover; choosing `reports/**` fills it in.
   - The limit fields say "Default: 50", "Default: $1.00", "Default:
     30m". Set 300 model calls and create it. **Expected:** saved, no
     error (no cap any more).
4. Settings › Jobs › **Cap** for model calls: set 200. Reopen the job.
   **Expected:** "At most 200 (Settings › Jobs)" under the field. Clear
   the cap afterwards.

   **Expected:** "Added the hook…". Again: "already has the hook".

   it exits 1.

   run): the tab closes.
5. 💲 New chat, **Run silently**: no tab, the agent still reads the
   page.
