What each release of Blitz brings, beyond the change list on [GitHub's releases page](https://github.com/retail-cortex/blitz/releases).

- [Blitz 0.7.2](blitz-0.7.2.md): no more frozen window with many workspaces open (the window and Blitz talk over one encrypted HTTP/2 connection); evals keep running when you leave them, with a time limit per case; skills get trigger phrases and scenarios you can try, keep and run; Studio is a menu, with its pages one click away; on Windows, Open Blitz opens the app, and the Edge window is gone.
- [Blitz 0.7.1](blitz-0.7.1.md): Studio for agents, evals, skills with scripts, rules, guardrails, secrets, workflows and workers; workflows on a canvas or composed with AI; a workspace dashboard that grades it all; a Windows setup program.
- [Blitz 0.7.0](blitz-0.7.0.md): a new desktop app on Electron, Windows included, that updates itself; web pages beside the chat, added to it or saved into the workspace; One Light and One Dark Pro themes; the chat or the editor expands over the other.
- [Blitz 0.6.5](blitz-0.6.5.md): branches and merges on the Changes page; version control in plain words; edits to rules, instructions and skills apply from the next message, with `/reload` to read them all again; braces in your rules no longer break Gemini turns.
- [Blitz 0.6.3](blitz-0.6.3.md): `/init` asks about your project and sets it up in one go; Pull, Push and merge conflicts on the Changes page; running workers can be stopped, and their instructions rewritten with AI; a dropped connection to the model reconnects instead of freezing the chat; no more macOS prompts for your personal folders.
- [Blitz 0.6.2](blitz-0.6.2.md): a turn no longer hangs when the agent asks for several approvals at once; the Mac tray stays out of the Dock; Linux software centres name Retail Cortex.
- [Blitz 0.6.1](blitz-0.6.1.md): quitting the Linux desktop app no longer crashes on NVIDIA graphics cards.
- [Blitz 0.6.0](blitz-0.6.0.md): Word export with equations, pictures and diagrams; pictures in every PDF; skills from registries such as Castor; history as a graph for files, folders and the workspace.
- [Blitz 0.5.4](blitz-0.5.4.md): `/spec` for research, data analysis and writing, every terminal command in the desktop app, and the user guide in the app.
- [Blitz 0.5.3](blitz-0.5.3.md): `/spec` and `/setup` from a specification, Gemini 4 Argon by default, a lighter idle window and native Mac menus.
- [Blitz 0.5.2](blitz-0.5.2.md): Go code blocks steady as you hover, and Go help in more projects.
- [Blitz 0.5.1](blitz-0.5.1.md): equations in Markdown and PDFs, pictures, zoom and full-width documents.
- [Blitz 0.5.0](blitz-0.5.0.md): the visual Markdown editor, and language servers in code blocks.
- [Blitz 0.4.0](blitz-0.4.0.md): Blitz on Windows.
- [Blitz 0.3.0](blitz-0.3.0.md): workspace search, a table viewer for CSV files, and Find in file.
